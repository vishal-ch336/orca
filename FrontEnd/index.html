Agentic Framework

Collaborative Agent Architecture

1. Safety & Hazard Agent
Evaluates wind, swell, and cyclone cones against craft limitations (traditional catamarans vs mechanized boats).
2. PFZ Oceanographic Agent
Cross-references thermal fronts with chlorophyll gradients to identify nutrient-rich pelagic fish aggregations.
3. Geospatial Routing Agent
Calculates obstacle-free transit corridors keeping vessels away from shallow shoals, breakers, and the IMBL border.
4. Explainability Agent
Attaches exact bulletin citations, timestamps, and verification sources so fisherfolk can verify every claim.
